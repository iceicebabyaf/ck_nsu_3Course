# One-Hot Encoder (TASK: DA-1-28)

## Описание
Реализация one-hot кодирования категориальных данных без использования `pandas.get_dummies`.  
Используется библиотека NumPy. Подходит для списков и массивов строк.

## Требования
- Python 3.8+
- numpy

Установка зависимостей: `pip install -r requirements.txt`
