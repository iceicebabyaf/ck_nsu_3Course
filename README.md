# Аналитика данных: Создание признаков по временным интервалам (DA-3-33)

## Описание задачи

Задача DA-3-33 посвящена созданию признаков на основе временных меток с использованием синтетических данных. Основная цель — извлечь день недели из временных меток, сгруппировать данные по этому признаку, рассчитать среднее и стандартное отклонение для количественных признаков, а затем добавить полученные агрегаты к исходному датафрейму. Результаты сохраняются в CSV-файл для дальнейшего анализа. Задача базируется на коде из репозитория DA-2-07, который предоставляет функции для работы с временными метками.

### Постановка задачи

- **Тип задачи**: Создание признаков: агрегаты по временным интервалам
- **Цель**: На основе кода из DA-2-07 создать признаки, представляющие среднее и стандартное отклонение по дням недели, и добавить их к исходному датафрейму.
- **Шаги**:
  1. Извлечь день недели из временных меток.
  2. Сгруппировать данные по дню недели.
  3. Рассчитать среднее (mean) и стандартное отклонение (std) для количественных признаков.
  4. Добавить полученные агрегаты к исходному датафрейму.
- **Репозиторий зависимости**: [DA-2-07](https://github.com/qbt29/DA-2-07)

### Структура проекта
```
├── lab_2

│   ├── README.md             # Описание репозитория DA-2-07
│   ├── requirements.txt      # Зависимости (pandas, matplotlib)
│   └── test-db.csv           # Тестовый CSV-файл с временными метками

│   └── result_synthetic.csv  # синтетика

```

- **main.py**: Основной скрипт, реализующий задачу DA-3-33. Импортирует функции из `lab_2/change_timeseries.py`, добавляет новую функциональность для создания агрегатов и сохраняет результаты в CSV.
- **lab_2/change_timeseries.py**: Содержит функции для загрузки данных, генерации синтетических временных меток, преобразования в формат datetime, извлечения признаков (день, месяц, год, час, день недели, квартал) и визуализации.
- **lab_2/test-db.csv**: Тестовый CSV-файл с временными метками для проверки работы на реальных данных.
- **output/result_synthetic.csv**: Выходной файл с синтетическими данными и добавленными признаками (создаётся при запуске `main.py --example_synthetic`).
- **[имя_файла]_result.csv**: Выходной файл для данных из CSV (например, `test-db_result.csv` при запуске с `test-db.csv`).

### Реализация

#### Основные функции
1. **Импорт из DA-2-07**:
   - Используются функции из `change-timeseries.py`:
     - `load_dataframe_from_file`: Загрузка данных из CSV.
     - `create_periodic_dataframe`: Генерация синтетических временных меток.
     - `convert_to_datetime`: Преобразование временных меток в формат datetime.
     - `extract_parts`: Извлечение признаков (день, месяц, год, час, день недели, квартал).
     - `display`: Визуализация распределения дней недели.
   - Путь к модулю добавляется через `sys.path.append(os.path.abspath('DA-2-07'))`.

2. **add_aggregates_by_weekday (main.py)**:
   - Принимает датафрейм с извлечёнными признаками и столбцом `timestamp`.
   - Проверяет наличие обязательных столбцов (`timestamp`, `day`, `month`, `year`, `hour`, `quarter`, `weekday`).
   - Группирует данные по `weekday` и рассчитывает среднее (`mean`) и стандартное отклонение (`std`) для столбцов `day`, `month`, `year`, `hour`, `quarter`.
   - Переименовывает столбцы в формат `{feature}_mean` и `{feature}_std` (например, `day_mean`, `day_std`).
   - Выполняет объединение с исходным датафреймом через `merge` по столбцу `weekday` с параметром `how='left'`.
   - Возвращает обновлённый датафрейм.

3. **example_main_synthetic (main.py)**:
   - Генерирует синтетические данные (15 временных меток с шагом 14 часов, начиная с 2025-09-16 02:35:00).
   - Вызывает `convert_to_datetime`, `extract_parts`, `add_aggregates_by_weekday`.
   - Сохраняет результат в `result_synthetic.csv`.

4. **main_read_file (main.py)**:
   - Загружает данные из указанного CSV-файла (например, `DA-2-07/test-db.csv`).
   - Выполняет те же шаги обработки, что и `example_main_synthetic`.
   - Выводит график (pie chart) для распределения дней недели.
   - Сохраняет результат в `[имя_файла]_result.csv`.

#### Результат
- **Выходной формат**: Датафрейм содержит исходные столбцы (`timestamp`, `day`, `month`, `year`, `hour`, `weekday`, `quarter`) и новые столбцы с агрегатами (`day_mean`, `day_std`, `month_mean`, `month_std`, `year_mean`, `year_std`, `hour_mean`, `hour_std`, `quarter_mean`, `quarter_std`).
- **Пример результата** (для синтетических данных, см. `result_synthetic.csv`):
  - Строки соответствуют исходным временным меткам.
  - Для каждого дня недели (`weekday`) добавлены средние и стандартные отклонения.
  - Если для какого-либо дня недели только одна запись, `std` будет `NaN` (ожидаемое поведение).
